- **PDF**: `@page A4 landscape` + 인쇄 파이프라인 → 1슬라이드=1페이지(잘림·빈페이지 0). 생성: `Workspace_API/deck_pdf_a4.py <url> "<제목>" 회사`.

- **스타일**: 화이트+차콜+레드 단일강조 · Pretendard · 중앙정렬 · 페이지네이션 n/15.
