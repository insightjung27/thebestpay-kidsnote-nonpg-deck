# 더베스트페이 → 키즈노트 결제·정산 백본 제안 (제안서)

키즈노트가 '통합 운영 OS'로 그리는 결제·정산 대시보드의 **백엔드**를, **3필러 결제·정산 백본**으로 함께 세우는 B2B 파트너십 제안. **제안서 표준 = 가로 A4 · 웹+PDF 겸용 · 인포그래픽 우선**(24장).

- **재포지셔닝(v6)**: 단일 훅(원가절감)→**3필러**. ①원가절감(논PG 처리원가 레이어) ②무중단(멀티밴 승인경로 이중화) ③통합정산(스마트알파 '정산 데이터' 정보 레이어). 키즈노트 5성장축·4허브·서비스루프·아키텍처·KPI·WBS에 정렬.
- **포맷**: A4 가로 슬라이드(논리 1280×905px). 슬라이드 1장 = A4 1페이지(WYSIWYG).
- **웹 프레젠테이션**: 키보드 `←/→·Space·F(전체화면)` + 측면 네비 화살표 + 상단 진행바. `#sN` 딥링크.
- **PDF**: `@page A4 landscape` + 인쇄 파이프라인 → 1슬라이드=1페이지. 생성: `Workspace_API/deck_pdf_a4.py <url> "<제목>" 회사`.
- **스타일**: 화이트+차콜+레드 단일강조 · Pretendard · 중앙정렬 · 페이지네이션 n/24 · 라운드 카드 스택 지양.
- **정직성/규제 가드(전 슬라이드)**:
  - 모든 수치 = `[예시]` + "귀사 실측 PoC로 확정" · 미확정 = `[발송 전 확정]` 자리표시 · 중립 예시 목업(실서비스 화면 아님).
  - '무중단' = 단일 실패점 제거·자동 전환 **설계 원리**(100% 가동 단정 아님).
  - 자금 = **카드사→기관 직접 정산 유지**(8·12·15·21장 동일 도식). **스마트알파 = 정산 데이터·집계·대사·리포팅 정보 레이어(수취·예치·지급대행 아님, 자금 미접촉)**.
  - dunning = 승인 재요청 트리거(채권추심·지급대행 아님) · rev-share 요율/수치 = 여전법 사인오프 전 대외 미표기 · 보육료(정부지원) = 정부 레일 대상 제외 · 우대율(규제 하한) 불변.
  - '엔진 공란' 단정 금지(기존 연동사 인정, '플랫폼 스케일 고도화 여지') · 무료 대체재 '해자' 단정 대신 build-vs-buy TCO·'확인 필요' · 내부 전략언어(록인·스위칭코스트) 렌더 금지.
- **★대외발송 전 J·법무 게이트 필수** — 자사 등록 지위(VAN/전자금융업/PG)·rev-share 여전법 구조·정산대행 재분류 여부 법무 서면 확인 전 발송 금지. 현재 배포 = Vercel 리뷰 URL(키즈노트 미발송).
